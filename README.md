# Сухие строительные смеси — сайт в коде

Каталог сухих смесей дилера ООО «Кирпичный трест» (Москва и МО): Perel, Dauer, Основит, Стройбриг, Promix.
План страниц — vault «Сухие смеси — разведка ассортимента и план страниц (09.10.2026)», «да» Влада 11.10.
Механика — из recke-code. Превью: https://smesi-sukhie-code.vercel.app (noindex, домена нет).

## Данные

- `data/records.json`, `data/products.json` — разбор 489 карточек Perel/Dauer/Основит (факты дословно,
  13 465 цитат сверены с текстом карточек: 0 расхождений). Сырьё и скрипты разведки — в рабочей папке клиента
  `recon/smesi-sukhie/`.
- `data/tksm_items.json` — ассортимент и цены действующего магазина клиента tk-sm.ru (обход 11.10.2026).
- `data/mapping.json` — какая позиция магазина какому товару производителя соответствует
  (same_product / renamed_same_product / not_on_manufacturer_site / not_dry_mix / unclear) с основанием.
- `data/other_brands.json` + `data/other_pages/` — Promix (tekato.ru) и Стройбриг (stroy-brig.ru): факты дословно,
  тексты страниц сохранены для сверки (877 цитат, 0 расхождений). BauMax: карточек на dauer.ru нет — не показываем.
- `data/images.json`, `data/img_src/` (не в git) — фото упаковок с карточек производителей (разрешение Влада 11.10).
- `scripts/build_positions.py` → `src/data/positions.json` + `public/assets/p/*.jpg`; отчёт — `data/build_report.json`.

## Правила

- Назначение и характеристики — дословно по производителю; адрес источника и дата сверки живут в данных и на страницу не выводятся.
- Цены — из магазина клиента tk-sm.ru («да» Влада 11.10). Только сухие смеси (слово Влада 11.10).
- Своих технических советов на страницах нет: выбор состава — факт производителя.
- «Дилер» не пишем (Влад 11.10). Телефон для сайта Влад пришлёт — пока номера магазина tk-sm.ru.
- Приём заявок не подключён — связь по телефону.

## Сборка и выкладка

```
python3 -I scripts/build_positions.py
npm run build
vercel deploy --prod --yes
```
