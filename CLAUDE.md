действующего магазина Николая tk-sm.ru («Торгкомплект») с его ценами. Бренды: Основит 59, Perel 31,
Стройбриг 16, Promix 14, Dauer 14. 16 страниц + 404.
Превью: **https://smesi-sukhie-code.vercel.app** (закрыто от поиска). Домена пока нет.

Документы проекта (копии на 14.10; актуальная передача — в Обсидиане Влада, читается через API доски, см. ниже):

## Правила (нарушение = работа не сделана)

1. **Только сухие смеси.** Грунтов, красок, паст, жидкой гидроизоляции нет. Цветные кладочные растворы и расшивка —
   соседний сайт «Цветные смеси», сюда не ставим.
2. **Назначение и характеристики — дословно с сайта производителя.** Ничего не досочинять, своих технических советов
   не писать. Позиция магазина без карточки у производителя на сайт не ставится — фактов нет.
3. **Цены — только из магазина tk-sm.ru** (слово Влада 11.10). Нет цены в магазине — «Цену назовём по телефону».
   Тексты tk-sm.ru не копировать — только ассортимент и цены.
4. **Слово «дилер» на сайте не писать** (Влад 11.10).
5. **Фото упаковок с сайтов производителей можно.** Каждый кадр смотреть глазами; маленький исходник не растягивать.
6. **Служебного на странице быть не должно** («уточнить», «по данным клиента», «TBD»). Всё, что лежит в `src/data/**`,
   может оказаться на экране — проверять собранный HTML (`dist/`), а не исходник. Подписи вариантов строит скрипт —
   вручную не вписывать.
7. **Приём заявок не подключён** (слово Влада): связь по телефону, форм нет. Метрику до домена не ставить.
8. **Пока нет домена — noindex в трёх местах** (метатег, `X-Robots-Tag` в `vercel.json`, `public/robots.txt`).
   Снятие — решение Влада при запуске.
9. **Живые сайты Николая на конструкторе mottor не трогать** (решение Влада 05.10) — только читать.
10. **Репозиторий открытый** — секретов (токены, пароли, ключи) не класть ни в код, ни в документы, ни в коммиты.
    Пуш в `main` сразу выкладывает сайт — пушить только собранное и проверенное локально.
11. **Решения, которых нет в `docs/`, — спрашивать Влада**, не додумывать. Открытые вопросы — в `docs/01-передача-14.10.md`, раздел «Что осталось».

## Как работать

```bash
npm ci                                    # зависимости строго по package-lock.json
npm run dev                               # локально, http://localhost:4321
python3 -I scripts/build_positions.py     # пересобрать каталог после правки data/ (positions.json руками не править)
npm run build                             # 17 страниц без ошибок
npx astro check                           # 0 ошибок
git push origin main                      # = выкладка: Vercel собирает и выкладывает сам
```

Сборщик позиций работает без исходников фото: готовые уменьшенные упаковки лежат в `public/assets/p/` (в git).
Исходники (`data/img_src/`, 206 МБ) в git не лежат; для новой позиции скачай картинку с карточки производителя
(у Perel, Dauer, Основит — поле `img` в `data/images.json`; у Promix и Стройбриг адреса картинки в данных нет — брать
со страницы `manufacturer_url` в `data/other_brands.json`) в `data/img_src/` под именем из поля `file`/`image_file`
(только имя файла, путь в данных записан с Мака Влада) — сборщик уменьшит её до 480 px (Pillow или `sips` на Маке).
На Windows вместо `python3 -I` — `py -3 -I`.

## «Готово» — только так

- Выложено и проверено на **выложенной** версии с `?v=<случайное>` на 1440, 768, 390 и 320 px:
  глазами каждую затронутую секцию **плюс клики** (меню на телефоне, фильтр брендов, окно характеристик, закрытие, ссылка с `#якорем`).
- Скрипты (из корня репозитория, адрес обязателен):
  - `python3 scripts/check_site.py https://smesi-sukhie-code.vercel.app` — все страницы × 4 ширины: код, один h1, нет
    прокрутки вбок, ошибок JS, битых и растянутых картинок, служебных фраз, внутренние ссылки живые. Пройдено =
    «проблемных 0» и «битых []». На 14.10: 68 проверок, проблемных 0. Список страниц — `scripts/_sections.json`
    (новый раздел — дописать туда).
  - `python3 scripts/check_ui.py https://smesi-sukhie-code.vercel.app` — клики (фильтр брендов и керамогранита, окно,
    Esc, открытие по `#якорю`) и контраст всех надписей. Пройдено = «ИТОГ w=…: OK» на всех 4 ширинах. На 14.10:
    плиточный клей — 24 позиции, Dauer 2, керамогранит 9, контраст 0, JS 0.
- Скрипты — помощники, не единственная правда (меню на телефоне они не проверяют — см. ниже).
- Браузер для скриптов — **только Playwright Chromium**, обычный Chrome скриптом не запускать.
- Локальный предпросмотр: перед съёмкой проверить по `<title>`, что порт отдаёт этот сайт.
- **Отчёт — на доске задач** (`yakobsonv.com/ru/cabinet/staff`, проект `kirpichtrest`): что сделано, ссылка на выложенную
  версию, как проверено.

## По задаче #50 — что чинить самому, а что только в отчёт

- **Чинить сам и выкладывать:** вёрстку и поведение — переливы, меню, окна, клики, контраст, отступы, картинки,
  которые уже есть.
- **Только в отчёт, без правки:** тексты, факты, цены, состав позиций, структуру страниц и всё из открытых вопросов
  `docs/01` — это решения Влада и Николая.
- **Уже известно (замер 14.10, 390 px):** меню на телефоне не закрывается тапом мимо панели (панель 68–344 px, тап
  ниже — `aria-expanded` остаётся `true`), а страница под открытым меню прокручивается. Esc закрывает. Это вёрстка — чинить.

## Грабли, уже наступленные

- Стили Astro не доходят до узлов, которые окно рисует скриптом (`innerHTML`) — стилизовать через `:global()` внутри
  родителя (11.10 цена слиплась с вариантом).
- В `.vercelignore` правило без слэша (`data`) выкинуло и `src/data` — удалённая сборка упала. Закрывать только корневые `/data`, `/scripts`, `/recon`, `/docs`.
- Папку `.vercel/` в другие репозитории не копировать — выкладка уйдёт не в тот проект.
- Связка позиции магазина с товаром производителя — по **коду модели** (AC12 ≠ AC121), а не по смыслу названия;
  связки `renamed_same_product` сборщик не проверяет — сверять глазами.
- Временная папка `/private/tmp` чистится — рабочие данные держать в репозитории.
