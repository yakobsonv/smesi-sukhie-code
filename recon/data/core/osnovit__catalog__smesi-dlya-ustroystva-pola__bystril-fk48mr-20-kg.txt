Комплексные решения Основит для пола
Качественный пол начинается с правильно подобранной смеси. В ассортименте представлены все необходимые материалы для подготовки основания: от черновых стяжек до финишных наливных покрытий. Продукты разделены на три основные группы — стяжки, ровнители и наливные полы — каждая из которых решает свои задачи на разных этапах ремонта. Составы Основит обладают высокой прочностью, устойчивостью к нагрузкам и совместимы с системой «теплый пол».
Виды смесей для пола и их назначение
Вся линейка разделена по функционалу и этапам устройства пола.
Стяжки для чернового выравнивания. Применяются для создания прочного основания с возможностью укладки слоем до 200 мм. Основит Стартолайн FC40 — базовая армированная стяжка для внутренних и наружных работ. FC41 H — высокопрочная версия для зданий с повышенной эксплуатационной нагрузкой. FC43 L — легкая стяжка с пониженной теплопроводностью и улучшенной звукоизоляцией, снижающая нагрузку на перекрытия на 40%.
Ровнители для предварительного и основного выравнивания. Предназначены для устранения неровностей перед укладкой финишных покрытий. Основит Ниплайн FK47 — универсальный самонивелирующийся состав для слоя 5–80 мм. Ниплайн FC47 — высокопрочный цементный ровнитель, выдерживающий нагрузки и подходящий для наружных работ.
Наливные полы для финишного выравнивания. Обеспечивают идеально гладкую поверхность под любые покрытия. Основит Ниплайн FC42 H — высокопрочный состав для слоя 3–30 мм. Скорлайн FK45 R — быстротвердеющий (хождение через 6 часов) для слоя 2–100 мм. Ровилайн FK46 — тонкослойный (0,5–10 мм) с высокой растекаемостью. Скорлайн FK48 R — универсальный быстротвердеющий для влажных помещений (слой 3–80 мм). Ровилайн FC49 — суперфинишный для «глянцевого» выравнивания слоем до 5 мм.
Как выбрать и где купить смесь для пола
Тип помещения и нагрузка: для жилых комнат подойдут базовые составы. Для коммерческих объектов, гаражей и наружных работ выбирайте высокопрочные смеси (FC41 H, FC47).
Толщина слоя: для выравнивания перепадов более 30 мм используйте стяжки (FC40, FC41 H, FC43 L) или ровнители с большим слоем (FK47, FK45 R). Для тонкой финишной подготовки (до 10 мм) — наливные полы (FK46, FC49).
Сроки: при необходимости быстрого продолжения работ выбирайте быстротвердеющие составы (FK45 R, FK48 R) с возможностью хождения через 6–12 часов.
Условия эксплуатации: для влажных помещений и теплых полов подходят влагостойкие и термостойкие составы — все перечисленные смеси совместимы с системой «теплый пол».
Использование правильно подобранной смеси гарантирует долговечность и надежность основания пола. Основит — профессиональные решения для строительства и ремонта. Ознакомиться с ассортиментом и найти ближайший магазин можно в разделе « Где купить » на нашем сайте.
