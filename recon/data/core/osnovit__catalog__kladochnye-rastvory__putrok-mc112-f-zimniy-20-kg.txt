Кладочные смеси Основит для прочной и надежной кладки
Кладочный раствор — основа долговечности и прочности любой кирпичной или блочной конструкции. Составы Основит обеспечивают надежное сцепление материалов, устойчивость к усадке и высокую морозостойкость. Они подходят для возведения стен, заборов, лестниц и других архитектурных элементов. В каталоге представлены стандартные, цветные, теплоизоляционные и зимние составы, а также специализированные клеи для ячеистых бетонов.
Виды растворов для кладки и их применение
Ассортимент включает смеси для разных типов материалов и условий работ.
Стандартные кладочные растворы — для кладки стен из рядового и облицовочного кирпича, а также для забутовки. Основит Рокформ MC110 (и зимний Рокформ MC110 F ) подходят для возведения несущих и самонесущих конструкций.
Цветные кладочные растворы — для облицовочного кирпича с возможностью расшивки шва в момент укладки. Линейка Основит Брикформ MC11 (и зимний Брикформ MC11 F ) применяются для кирпича с водопоглощением до 12%. Брикформ MC11/1 (и зимний белый Брикформ MC11/1 F ) — для кирпича с высоким водопоглощением (более 12%) и кирпича ручной формовки. Палитра — до 34 цветов.
Теплоизоляционные растворы — для кладки стен из легких пустотелых керамических блоков и блоков на пористых заполнителях. Основит Путформ MC114 (и зимний Путформ MC114 F ) снижают теплопотери через кладочные швы. Путформ MC114 L — высокоэффективный состав с повышенными теплоизоляционными свойствами и увеличенным выходом раствора.
Монтажные клеи для ячеистых бетонов — для тонкослойной кладки блоков из газо- и пенобетона, газосиликата. Основит Техно MC112 (и зимний Техно MC112 F ) обеспечивают высокую прочность сцепления при минимальной толщине шва (2–5 мм). Это надежный раствор для кладки камня и блоков с геометрически точными гранями.
Как выбрать и где купить кладочную смесь Основит?
Определите тип материала: Для рядового кирпича выбирайте MC110. Для облицовочного кирпича — цветные составы MC11 или MC11/1. Для легких блоков — теплоизоляционные смеси MC114. Для газобетона — монтажный клей MC112.
Учтите условия работ: Для кладки при отрицательных температурах (до -10°C) выбирайте составы с маркировкой F.
Учитывайте водопоглощение кирпича: Для материала с водопоглощением более 12% требуется специальный раствор MC11/1.
Для светлых финишных покрытий используйте белую штукатурку РС117 W, чтобы избежать изменения оттенка декоративного слоя.
Правильно подобранная смесь гарантирует прочность, долговечность и эстетичный внешний вид вашей постройки.
