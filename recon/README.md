# Сухие смеси — сырьё разведки ассортимента (09.10.2026)

Источник фактов для будущего сайта «Сухие строительные смеси» (дилер ООО «Кирпичный трест»).
Сайт ещё не собирается — ждёт «да» Влада на план страниц
(vault: `Николай (стройматериалы)/Сухие смеси — разведка ассортимента и план страниц (09.10.2026).md`).

## Что здесь

- `data/products.json` — 489 карточек товара трёх производителей (td-perel.ru, dauer.ru, osnovit.ru):
  адрес, разделы каталога производителя, ссылки на PDF со страницы.
- `data/records.json` — разбор каждой карточки: назначение, фасовка, расход, толщина, норматив,
  до 14 характеристик — **дословно**; наш тип (`type`), сухая ли смесь (`is_dry_mix`),
  ключ товара без цвета и фасовки (`series_key`). 13 465 цитат сверены с текстом карточки
  скриптом `scripts/verify.py` — несовпадений 0.
- `data/core/` — «ядро» текста каждой карточки (меню и подвал срезаны) — по нему сверять факты при сборке.
- `data/sections.json` — разделы будущего сайта × производитель (товары).
- `data/categories.json` — разделы каталогов производителей.
- `data/batch_notes.json` — заметки разбора по пачкам: противоречия внутри карточек производителей.
- `data/brief.md` — бриф, на котором строился план страниц.
- `scripts/` — обход каталогов (`crawl.py`, через curl), выделение ядра (`prep.py`), проверка
  дословности (`verify.py`), сводка по разделам (`sections.py`), таблица xlsx (`build_xlsx.py`).

Сырые HTML-страницы (225 МБ) не сохранялись: обход повторяется за ~10 минут `scripts/crawl.py`.
